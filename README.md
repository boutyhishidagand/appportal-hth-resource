# appportal-hth-resource

## 项目简介

本仓库用于归档和发布多个独立的 HTML 页面。这些页面涵盖各类应用或功能的辅助界面、静态资源展示或交互原型，不针对任何特定域名或具体网站。

## 目录说明

```
├── pages/          # 存放所有 HTML 页面文件
├── assets/         # 公共资源文件（CSS、JS、图片等）
├── docs/           # 额外文档或说明
└── README.md       # 本文件
```

各页面按功能或用途存放在 `pages/` 目录下，资源文件统一放置在 `assets/` 中以便复用。

## 页面归档说明

- 每个 HTML 页面为一个独立单元，可直接通过浏览器打开运行。
- 页面之间无强依赖关系，可按需使用或修改。
- 部分页面可能引用 `assets/` 下的公共资源，请确保路径正确。

## 维护说明

- 新增页面时，请在 `pages/` 下创建新目录或直接添加文件，并保持命名清晰。
- 若页面需要额外资源（样式表、脚本等），请放入 `assets/` 对应子目录。
- 本仓库不追踪具体部署环境或线上地址，所有页面均为静态归档用途。

## 使用方式

1. 克隆或下载本仓库到本地。
2. 打开 `pages/` 下任意 HTML 文件即可查看对应页面。
3. 可根据需要自行修改或扩展。
